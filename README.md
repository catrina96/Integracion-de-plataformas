# Peluditos Pet Chile - Entrega 1

**Proyecto:** Gestión de posibles clientes y oportunidades comerciales  
**Equipo:** Catalina Ríos, Renato [Apellido], Víctor [Apellido]  
**Propósito:** Proponer y prototipar una solución basada en BPMN y servicios Java para mejorar el ciclo de vida de clientes del emprendimiento.

## Resumen
Peluditos Pet Chile elabora y vende pastelería para mascotas. Actualmente las consultas llegan por redes sociales y no existe un registro formal ni seguimiento. La solución propuesta usa **BPMN + Flowable** (prototipo) y **web services Java** para registrar posibles clientes, gestionar seguimientos y generar oportunidades comerciales en fechas relevantes.
